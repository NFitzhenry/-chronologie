# Chronologie

A chronology card game. Each card is a historical event; place it in the right gap on a growing timeline
(a *frise chronologique*). The year is revealed once the card is placed.

Play it at the GitHub Pages address for this repository.

## Contents

- `index.html`: the whole game in one page (no build step).
- `art/`: card pictures from Wikimedia Commons. Each card shows its picture's artist and licence, with a link
  to the Commons file page.
- `setup/supabase-setup.sql`: optional database for nickname-and-PIN accounts and a leaderboard. Without it,
  progress is kept in each player's browser.

## Friezes

History of France, History of South Africa, Middle East and North Africa, and History of medicine, with four
specialist packs bought with points.
